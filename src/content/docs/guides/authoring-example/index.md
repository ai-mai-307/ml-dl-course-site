Эта страница показывает, как выглядит обычный Markdown на сайте. Исходный файл можно редактировать в Obsidian.[^example]

## Текст и ссылки

Поддерживаются **жирное начертание**, *курсив*, `короткие фрагменты кода` и стандартные ссылки.
Можно перейти к [таблице ниже](#таблица) или вернуться в [раздел инструкций](../).

## Формулы

Формулу можно включить в предложение: $a^2 + b^2 = c^2$.
Более длинное выражение располагается отдельно:

$$
\bar{x} = \frac{1}{n}\sum_{i=1}^{n} x_i.
$$

## Код

```python
values = [1, 2, 3]
mean = sum(values) / len(values)
print(f"Среднее: {mean:.1f}")
```

## Примечания

> [!NOTE] Обычный Markdown
> Внутри примечания работают **выделение**, [ссылки](#формулы) и формулы: $n = 3$.
>
> - Сначала напишите текст.
> - Затем проверьте результат на странице.

> [!TIP]- Подробнее о примере
> Этот блок можно раскрыть мышью или клавишами Enter и пробел.
>
> $$
> \bar{x} = \frac{1 + 2 + 3}{3} = 2.
> $$
