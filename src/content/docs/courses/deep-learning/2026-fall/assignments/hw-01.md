## 1. Реализовать класс `MLP`

Создайте класс `MLP` или `NeuralNetwork`, экземпляр которого представляет собой полносвязную нейронную сеть с произвольным количеством слоёв.

Пример интерфейса:

```python
class MLP:
    def __init__(
        self,
        layers: list[int],              # например: [784, 100, 50, 10]
        activation: str = "relu",       # "sigmoid" | "tanh" | "relu"
        weight_init: str = "xavier",    # "constant" | "normal" | "xavier" | "kaiming"
        dtype=np.float32,
        seed: int | None = 42,
    ):
        ...

    def forward(self, X: np.ndarray) -> np.ndarray:
        """Возвращает логиты."""
        ...

    def backward(self, dL_dlogits: np.ndarray) -> None:
        """Вычисляет градиенты dW и db."""
        ...

    def zero_grad(self) -> None:
        """Обнуляет накопленные градиенты."""
        ...

    def parameters(self) -> list[tuple[np.ndarray, np.ndarray]]:
        """Возвращает [(W_0, b_0), ..., (W_{L-1}, b_{L-1})]."""
        ...

    def predict(self, X: np.ndarray) -> np.ndarray:
        """Возвращает предсказанные метки классов."""
        ...
```

### Как интерпретировать `layers`

Например:

```python
layers = [784, 100, 50, 10]
```

означает:

- вход — 784 признака;
- первый скрытый слой — 100 нейронов;
- второй скрытый слой — 50 нейронов;
- выход — 10 логитов.

Fashion-MNIST содержит изображения размером `28 × 28`, поэтому после flatten входная размерность равна:

```text
28 × 28 = 784
```

4. Функции активации:

1. Возможность управлять начальной инициализацией смещений `b`, необходимую для исследовательских экспериментов.
