> [!WARNING] **Инструкция требует обновления.**
> На осенний семестр 2026 года грантовый доступ к Yandex DataSphere для текущих курсов пока не предоставлен, а интерфейс и порядок работы сервиса заметно изменились. Шаги ниже перенесены из предыдущей версии курса и могут не соответствовать текущему интерфейсу.

1. Принимаете задание в GitHub Classroom, кликнув на ссылку, которую я прикладываю в топике “Инфо” нашего чата![Приглашение к заданию в GitHub Classroom.](./assets/classroom-invitation.png);
2. Автоматически создается репозиторий в рамках GitHub организации;
3. Нажимаете зеленую кнопку “Clone”, раздел HTTPS, копируете строку![HTTPS-ссылка репозитория для клонирования.](./assets/repository-https-url.png);
4. Открываете Yandex Datasphere, нажимаете на левой панели вкладку “Проекты”, находите свой![Список проектов в Yandex Datasphere.](./assets/datasphere-projects.png);
5. Нажимаете на вкладку “Участники”, чтобы увидеть, что ваша команда имеет роль “Developer”![Участники проекта и роль команды Developer.](./assets/project-members.png);
6. Открываете проект и ждете некоторое время, пока он откроется![Открытие проекта Yandex Datasphere.](./assets/open-project.png);
7. В открывшемся интерфейсе Jupyter Lab на верхней панели нажимаете вкладку “Git”, затем “Clone Repository”![Команда Clone Repository в меню Git в Jupyter Lab.](./assets/git-clone-menu.png);
8. В открывшемся окне вводите ссылку, которую вы скопировали на шаге 3. этой инструкции![Диалог ввода ссылки на репозиторий.](./assets/clone-repository-dialog.png);
9. Вводите свой ник и GitHub токен, который вы можете найти в сообщении чата по  [ссылке![Диалог ввода GitHub-имени и токена.](./assets/github-authentication.png)](https://t.me/c/3075180202/7/308);
10. После этого вы увидете в корне вашего проекта склонированный репозиторий![Склонированный репозиторий в проекте.](./assets/cloned-repository.png);
11. Перейдите в директории склонированного репозитория и нажмите значок Git на левой панели – это GUI интерфейс работы с Git в рамках Yandex Datasphere![Панель Git в Jupyter Lab.](./assets/git-panel.png).
