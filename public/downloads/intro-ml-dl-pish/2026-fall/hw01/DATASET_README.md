# Происхождение данных и список изменений

Этот файл описывает `diamonds_hw01.csv`, используемый в ДЗ №1.

## Источник

- Оригинальный набор **diamonds** (53 940 объектов, 10 столбцов) из **ggplot2**.
- Данные получены из локально установленного пакета `plotnine.data.diamonds` (Python-версия набора `ggplot2::diamonds`).
- Документация автора: https://ggplot2.tidyverse.org/reference/diamonds.html
- Описание признаков: https://ggplot2.tidyverse.org/reference/diamonds.html

## Что изменено при подготовке учебного датасета

1. Исключены записи с нулевым размером хотя бы по одной из осей `x`, `y`, `z` — это физически некорректные габариты.
2. Воспроизводимым случайным отбором выбрано **12 000 объектов** (`random_state=42`). Все выбранные записи происходят из исходной таблицы.
3. Исходный категориальный `cut` преобразован в **целевую переменную `high_cut`**: `1` при `Ideal` или `Premium`, иначе `0`. Исходный `cut` удалён, чтобы готовый ответ не попадал в признаки.
4. `price` переименован в `price_usd`, `x/y/z` — в `length_mm/width_mm/height_mm`, `depth/table` — в `depth_pct/table_pct`.
5. Для тренировки методов заполнения пропусков искусственно удалены значения (фиксированный генератор `np.random.default_rng(2026)`): `carat` — **300**, `depth_pct` — **240**, `clarity` — **360**. Это **учебное изменение**: в оригинальных записях пропусков не было.
6. Оставлены **8 признаков и 2 цели**, все остальные значения оригинальных записей сохранены.

## Итоговая структура

- **12 000 строк × 10 столбцов**.
- Признаки: `carat`, `depth_pct`, `table_pct`, `length_mm`, `width_mm`, `height_mm`, `color`, `clarity`.
- Цель классификации: `high_cut` (0/1; число положительных объектов: 7827; число отрицательных: 4173).
- Цель регрессии: `price_usd` (USD).
- Тестовые/валидационные строки определяются **в ноутбуке**, не в CSV.

Важно: учебный датасет предназначен для знакомства с ML и не должен использоваться для реальной оценки рыночной стоимости ювелирных изделий.
